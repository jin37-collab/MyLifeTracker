# v1.1 변경 사항

## 일정 화면 종료 문제 대응

- 이전 버전의 ID 생성 방식(`현재 시각 + 작은 난수`)에서 매우 짧은 시간에 여러 항목이 만들어질 때 ID가 겹칠 가능성을 제거했습니다.
- 기존 저장 데이터에 중복 ID가 있으면 앱 시작 시 자동으로 새 ID를 부여합니다.
- 할 일/일정 목록 렌더링이 항목 ID를 Compose LazyColumn의 필수 key로 사용하지 않게 바꿔, 과거 데이터에 중복 ID가 남아 있어도 목록 진입이 종료 원인이 되지 않게 했습니다.

## 홈 화면 위젯

- 미완료 할 일 수
- 오늘 일정 수
- 이번 달 소비
- 이번 달 수입
- 월 수입 목표 달성률

앱에서 데이터를 변경할 때 위젯을 즉시 갱신하고, 시스템 주기 갱신도 설정했습니다.

## 앱 아이콘

- 밝은 배경
- 블루 원형 체크
- 작은 그린 포인트

## 계정 및 클라우드 저장

- 이메일/비밀번호 회원가입 및 로그인
- Firebase Authentication REST API 사용
- Firebase Realtime Database REST API 사용
- 각 사용자 데이터는 `/users/{uid}/tracker` 아래에 저장
- 로그인 상태의 변경 사항은 로컬 저장 후 클라우드에도 자동 저장
- 재설치/새 기기에서 기존 계정 로그인 시 클라우드 데이터를 복원
- Firebase ID Token 만료 시 Refresh Token으로 자동 갱신

## 저장되는 항목

- 할 일 전체
- 일정 전체
- 소비 내역 전체
- 수입 내역 전체
- 카드 3종의 이름/월 실적 목표
- 월 수입 목표

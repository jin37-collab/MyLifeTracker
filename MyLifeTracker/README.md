# 나의 트래커 Android v1.1

Kotlin + Jetpack Compose로 만든 개인 생활 관리 앱입니다.

## 이번 버전에서 추가/수정된 내용

- 일정 탭 크래시 방어
  - 과거 버전에서 중복될 수 있었던 항목 ID를 앱 시작 시 자동 복구
  - 일정/할 일 LazyColumn이 중복 ID 때문에 종료되지 않도록 고유 key 의존 제거
  - 새 항목 ID는 충돌하지 않는 단조 증가 방식으로 생성
- 홈 화면 Android 위젯
  - 미완료 할 일 수
  - 오늘 일정 수
  - 이번 달 소비/수입
  - 월 수입 목표 달성률 바
  - 앱 데이터 변경 시 즉시 갱신 + 시스템 주기 갱신
- 새 미니멀 앱 아이콘
  - 블루 체크 + 그린 포인트 디자인
- 클라우드 계정/동기화
  - 이메일/비밀번호 회원가입 및 로그인
  - Firebase Realtime Database에 사용자별 데이터 저장
  - 기존 휴대폰 데이터를 새 계정에 처음 업로드
  - 재설치/새 기기에서 로그인 시 기존 클라우드 데이터 복원
  - 로그인 상태에서는 데이터 변경 후 자동 업로드
  - 홈 우측 상단 계정 아이콘에서 수동 동기화/로그아웃 가능
- 로컬 저장 유지
  - 네트워크가 없어도 기기 저장 데이터로 앱 사용 가능

## 기존 기능

- 홈: 할 일/오늘 일정/소비/수입 요약, 마감 임박 할 일, 오늘 일정, 카드 실적, 수입 목표
- 할 일: 마감일 선택, 마감일 있는 할 일을 상단 날짜순 정렬, 무기한 할 일 분리, 카테고리 필터
- 일정: 오늘부터 180일을 날짜별로 연속 세로 스크롤
- 소비: 식사/카페/데이트/의류/물건, 카드 3종 선택, 최근 소비 내역
- 카드 실적: 월 목표 대비 달성률 및 남은 비율
- 수입: 월 목표 원형 달성률, 최근 수입 내역

## 클라우드 설정

`FIREBASE_SETUP.md`를 먼저 따라 주세요.

Firebase 값을 넣지 않고 빌드해도 앱과 로컬 저장/위젯은 작동하지만, 로그인 화면에서는 클라우드 설정이 필요하다고 표시됩니다.

## 위젯 추가

업데이트 APK를 설치한 뒤 Android 홈 화면의 빈 곳을 길게 누르고 **위젯 → 나의 트래커**를 찾아 추가합니다. 기종/런처에 따라 메뉴 이름은 조금 다를 수 있습니다.

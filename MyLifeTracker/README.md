# 나의 트래커 (Android)

Kotlin + Jetpack Compose로 만든 개인 생활 관리 앱입니다.

## 구현된 기능

- 홈: 이번 달 할 일/오늘 일정/소비/수입 요약, 마감 임박 할 일, 오늘 일정, 카드 실적, 수입 목표
- 할 일: 마감일 선택 입력, 마감일 있는 할 일을 상단 날짜순 정렬, 마감일 없는 할 일 분리, 카테고리 필터, 완료/삭제
- 일정: 오늘부터 45일을 날짜별로 세로 연속 스크롤, 일정 추가/삭제
- 소비: 금액 + 5개 카테고리(식사/카페/데이트/의류/물건), 카드 3종 선택, 메모, 최근 소비 내역
- 카드 실적: 카드별 월 목표 대비 달성률/남은 퍼센트 바, 카드 이름 및 목표 금액 수정
- 수입: 월 목표 원형 달성률, 수입 추가/삭제, 최근 수입 내역, 목표 수정
- 로컬 저장: SharedPreferences + JSON. 앱을 종료해도 데이터 유지

## 실행

1. Android Studio에서 이 폴더를 엽니다.
2. Gradle Sync를 실행합니다.
3. Android 8.0(API 26) 이상 에뮬레이터/기기를 선택합니다.
4. Run `app`을 실행합니다.

첫 실행에는 UI 확인용 샘플 데이터가 들어갑니다. 이후 추가/삭제한 데이터는 기기에 저장됩니다.

## 바꾸기 좋은 곳

- 카드 3종 이름/실적 목표: 앱의 소비 탭 > 카드 설정
- 월 수입 목표: 수입 탭 > 목표 수정
- 앱 이름/패키지명: `AndroidManifest.xml`, `app/build.gradle.kts`
